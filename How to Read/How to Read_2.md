# 🎤 15 MIN — INTERVIEW MODE

**Close all notes.**

Pick 3 questions.

Answer each **out loud**.

### Answer structure

```text
1. Definition
2. Why it is needed
3. How it works
4. Real-world example
5. Trade-offs
```

Example:

> **What is Redis?**

Don't just say:

> "Redis is an in-memory database."

Instead:

> "Redis is an in-memory key-value store commonly used for caching, sessions, rate limiting and temporary data. Because data is primarily served from memory, it provides very low latency. In a FastAPI application, I could use Redis to cache frequently requested company data and reduce database load. The trade-off is that cached data can become stale and Redis requires additional infrastructure."

**That's an interview answer.**
